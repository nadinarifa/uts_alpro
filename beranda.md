## Deskripsi Singkat Program

Program ini adalah program console berbahasa C++ yang membantu bendahara atau panitia kegiatan mahasiswa untuk memeriksa penggunaan anggaran. Pengguna memasukkan nama komponen, anggaran rencana, dan realisasi pengeluaran, lalu program menghitung selisih dan persentase penyimpangan dari anggaran rencana. Program menentukan status tiap komponen (Hemat, Tepat, atau Melebihi Anggaran), keterangan Perlu Evaluasi atau Peringatan jika terjadi kelebihan. Pemeriksaan dapat diulang untuk banyak komponen, dan di akhir program menampilkan rekapitulasi serta kesimpulan kondisi anggaran kegiatan secara keseluruhan.
